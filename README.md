# 📊 SQL Style Business Analysis with Pandas

## 📌 Project Overview

This project demonstrates SQL-style data analysis using Python and Pandas.

It covers grouping, aggregation, sorting, pivot tables, and business insights through data visualization.

---

## 🛠️ Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Kaggle Notebook

---

## 📁 Dataset

Global Superstore Dataset

## 📌 Project Tasks

- Data Loading
- Data Cleaning
- SQL-style Analysis
- GroupBy Operations
- Pivot Tables
- Business KPIs
- Data Visualization
- Business Insights

---

## 📊 Visualizations

- Sales by Category
- Sales by Region
- Top Customers
- Top Products
- Monthly Sales Trend

This project demonstrates beginner-level SQL-style data analysis using Pandas and business reporting.
